# 第二章 线性表：PTA 程序填空题

## 程序填空题

### 顺序表删除

在长度为 `L.length` 的顺序表中删除第 `i` 个元素。原题 `for (int j = i; j <= L.length; j++)` 的循环条件多执行了一次。以下是修正后的完整函数。

**答案：**

```cpp
int ListDelete_Sq(SqList &L, int i)
{
    if (i < 1 || i > L.length) return ERROR;

    for (int j = i; j < L.length; j++) {
        L.elem[j - 1] = L.elem[j];
    }

    L.length--;
    return OK;
}
```

### 单链表删除

在带头结点的单链表中删除第 `i` 个元素。第一个空为 `p->next && j < i - 1`，第二个空为 `p->next = q->next;`。

**答案：**

```cpp
int ListDelete_L(LinkList &L, int i)
{
    LinkList p;
    LinkList q;
    int j;

    p = L;
    j = 0;

    while (p->next && j < i - 1)
    {
        p = p->next;
        ++j;
    }

    if (!(p->next) || j > i - 1)
    {
        return ERROR;
    }

    q = p->next;
    p->next = q->next;
    delete q;

    return OK;
}
```
